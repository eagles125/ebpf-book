# 全书章节任务扩展草案

> 目标：将《eBPF 从入门到精通：原理、内核实现与实战可移植开发》的 25 章与 4 个附录拆解为可独立分配给子代理的任务清单。
>
> 执行原则：每章可由独立子代理完成，但主代理在标记完成前，必须对照 `book/STYLE.md`、`book/README.md`、OpenSpec 任务格式与本清单的验收项逐项核验。
>
> 统一要求：每章都应包含完整中文正文、可运行或明确标注验证状态的示例、必要的独立示例资产、文本可视化、参考来源与主代理复核步骤。

## 总体工作流

- [ ] 将每一章视为独立交付单元，允许由不同子代理并行撰写。
- [ ] 每章完成后，主代理必须核对章节结构是否覆盖学习目标、原理解析、内核实现分析、实战、可视化、常见问题与排错、总结、参考来源。
- [ ] 每章完成后，主代理必须核对术语、代码块、命令说明、验证标注是否符合 `book/STYLE.md`。
- [ ] 涉及可执行示例的章节，主代理必须确认示例文件路径、编译命令、运行命令、预期输出和验证状态都已写清。
- [ ] 涉及 `book/examples/` 的章节，主代理必须确认章节正文与独立示例资产双向交叉引用一致。
- [ ] 主代理不得在缺少参考来源或验证标注时关闭任务。
- [ ] 若章节依赖前文概念，任务中必须显式写出依赖前置章节，而不是默认读者已知。
- [ ] 若章节涉及特权环境、内核版本或发行版差异，任务中必须显式写出环境前提与限制。
